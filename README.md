# Avito-Data-Science-Bootcamp

Тестовое задание для Avito Bootcamp по NLP и LLM

## 03_final

Финальная версия решения. Основное изменение - к двум текстовым сигналам из предыдущей версии добавлен третий канал: char n-grams для начала описания объявления

Заголовок объявления по-прежнему представляется символьными n-граммами длины 3–5. Такой подход лучше работает со словоформами и частично устойчив к опечаткам

Описание объявления обрабатывается двумя способами:

- word-level TF-IDF для первых 1000 символов
- char n-grams длины 3–5 для первых 400 символов

Дополнительный char-level канал для описания позволяет учитывать разные словоформы и частичные совпадения, которые word-level TF-IDF может пропускать

Также используется история взаимодействий из `train.parquet`. Для точных совпадений поискового запроса добавляются объявления, которые уже встречались с этим запросом. Используется до 10 наиболее частых объявлений

## Веса

Итоговый score состоит из трёх частей:

- 55% - сходство заголовков
- 20% - сходство описаний через word-level TF-IDF
- 25% - сходство описаний через char n-grams

Такие веса были выбраны после подбора параметров на локальной валидации. Заголовок оказался наиболее сильным текстовым сигналом, поэтому получил наибольший вес

Word-level TF-IDF по описанию даёт дополнительную информацию, но его вклад оказался меньше. При этом char n-grams по описанию дали полезный дополнительный сигнал за счёт работы со словоформами и частичными совпадениями, поэтому их вес оказался выше обычного TF-IDF по описанию

## Результат

Локальная валидация **Recall@50 = 0.253235**

На Степике: **Recall@50 = 0.275939**
