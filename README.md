# Avito-Data-Science-Bootcamp

Тестовое задание для Avito Bootcamp по NLP и LLM

## 02_improved

Улучшенная версия baseline. Основное изменение - заголовок объявления теперь представляется символьными n-граммами длины 3–5. Такой подход лучше работает со словоформами и частично устойчив к опечаткам

Описание объявления по-прежнему обрабатывается через word-level TF-IDF, но ограничивается первыми 400 символами

Итоговый score состоит из двух частей:

- 80% - сходство заголовков
- 20% - сходство описаний

## Результат

Локальная валидация **Recall@50 = 0.245901**

У baseline было **0.166923**, поэтому локальный Recall заметно вырос за счёт перехода заголовка на символьные n-граммы и объединения двух текстовых сигналов

На Степике: **Recall@50 = 0.262771**

## Запуск
Установить зависиомсти
```bash
pip install -r requirements.txt
```
Разместить `train.parquet` `benchmark_queries.parquet` `benchmark_items.parquet` в корень проекта
```bash
python main.py
```
После запуска создаётся файл `answer.csv` в корне проекта
